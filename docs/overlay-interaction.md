# 浮窗三态交互（API v2）

本接口从 Relink 1.0.6 补丁 1 起支持。使用完整三态交互的插件应声明 apiVersion: 2；旧宿主不会启用该插件。

`window.resize` 授权下，`setDisplayState('notch' | 'compact' | 'expanded')` 请求宿主调整画布；`notch` 仅允许游戏模式使用。宿主先为展开留出空间，收回时保留 600 ms 的动画画布，再缩小原生窗口。插件不应逐帧请求原生窗口尺寸。

浮岛交互规则：

- 游戏内移入刘海，只恢复为收起的浮岛；点击浮岛后才展开。
- 展开后，左键或右键点击外部立即收回。桌面回到收起浮岛，游戏内回到刘海。
- 只移开鼠标、没有点击时，保留 3 秒缓冲；移回来取消计时。
- 外部点击收回后，窗口尺寸变化产生的合成移入事件不会重新打开；再次移动鼠标进入后可恢复。

`onDismiss(callback)` 订阅宿主过滤后的收回事件。Windows 游戏浮窗不获取键盘焦点，因此不能仅靠 `blur` 检测外部点击。宿主使用事件驱动的鼠标按钮监听，始终把事件传递给原应用；插件不会收到全局坐标、按键或其他应用内容。最后一个插件窗口关闭时结束监听，父进程退出也会清理原生监听。

标题和图标在淡出后切换。文字排版使用固定宽度，外壳弹簧动画单独控制尺寸；保留反向动画的速度，支持系统减少动态效果设置。

验证覆盖桌面与模拟游戏状态、非焦点窗口、真实系统左右键、点击穿透、连续反向动画、音乐轮询期间标题稳定性。模拟游戏不等同于所有游戏的独占全屏兼容性或游戏帧率测试。

实现参考：[Microsoft LowLevelMouseProc](https://learn.microsoft.com/en-us/windows/win32/winmsg/lowlevelmouseproc)、[Electron screen](https://www.electronjs.org/docs/latest/api/screen)。
