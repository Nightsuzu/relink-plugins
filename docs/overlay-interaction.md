# 浮窗三态交互（API v2）

本接口从 Relink 1.0.6 补丁 1 起支持。使用完整三态交互的插件应声明 apiVersion: 2；旧宿主不会启用该插件。

`window.resize` 授权下，`setDisplayState('notch' | 'compact' | 'expanded')` 请求宿主调整画布；`notch` 仅允许游戏模式使用。宿主保持原生画布的尺寸与屏幕锚点固定，收回时为过渡保留 600 ms，再把可交互区域缩到可见浮岛；透明余量允许点击穿透。插件不应逐帧请求原生窗口尺寸。

浮岛交互规则：

- 游戏内鼠标连续可见至少 200 ms、前台窗口未捕获鼠标且未锁定时，移入刘海只恢复为收起的浮岛；点击浮岛后才展开。
- `hoverAllowed: false` 表示游戏正在隐藏或锁定鼠标，或尚未取得可靠的鼠标状态。此时宿主强制收回刘海、拒绝展开并启用鼠标穿透；恢复可见后，需真实移动鼠标才能重新触发。
- 展开后，左键或右键点击外部立即收回。桌面回到收起浮岛，游戏内回到刘海。
- 只移开鼠标、没有点击时，保留 3 秒缓冲；移回来取消计时。
- 外部点击收回后，命中区域变化产生的合成移入事件不会重新打开；再次移动鼠标进入后可恢复。

`onDismiss(callback)` 订阅宿主过滤后的收回事件。Windows 游戏浮窗不获取键盘焦点，因此不能仅靠 `blur` 检测外部点击。宿主使用事件驱动的鼠标按钮监听，始终把事件传递给原应用；插件不会收到全局坐标、按键或其他应用内容。原生辅助进程每 100 ms 检查光标可见性、前台窗口鼠标捕获和极小锁定区域，仅在状态变化时通知宿主；插件只收到 `hoverAllowed`，不会收到全局坐标。最后一个插件窗口关闭时结束监听，父进程退出也会清理原生监听。

标题和图标在淡出后切换。展开与收起共用固定宽度的标题布局，文字层只淡入淡出，外壳弹簧动画单独控制尺寸；保留反向动画的速度，支持系统减少动态效果设置。

若另一台电脑没有动画，先在 Relink → 设置 → 插件 → Relink 浮岛 → 插件设置，查看“跟随系统动画设置”。默认开启，尊重 Windows 的减少动画偏好；关闭后仅浮岛启用完整动画，不修改系统设置。形态、文字淡入淡出和环绕光效使用同一策略，设置即时生效。环绕光效还需单独开启，并在播放音乐时显示；游戏刘海状态暂停环绕。Windows 11 对应设置位于“设置 → 辅助功能 → 视觉效果 → 动画效果”。该选项属于后续补丁，已发布的浮岛 0.3.1 尚无此选项。

动画按实际推进的弹簧时间收敛。首帧因调度或显卡繁忙延迟时，不再仅因墙钟时间超过 540 ms 就直接跳到终点。此修正不代表所有显卡或独占全屏环境均已实测。

验证覆盖桌面与模拟游戏状态、非焦点窗口、真实系统左右键、点击穿透、连续反向动画、音乐轮询期间标题稳定性。模拟游戏不等同于所有游戏的独占全屏兼容性或游戏帧率测试。

实现参考：[Microsoft LowLevelMouseProc](https://learn.microsoft.com/en-us/windows/win32/winmsg/lowlevelmouseproc)、[Electron screen](https://www.electronjs.org/docs/latest/api/screen)。
