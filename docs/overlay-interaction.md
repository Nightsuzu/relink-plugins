# 浮窗三态交互（API v2）

本接口从 Relink 1.0.6 补丁 1 起支持。使用完整三态交互的插件应声明 apiVersion: 2；旧宿主不会启用该插件。

`window.resize` 授权下，`setDisplayState('notch' | 'compact' | 'expanded')` 请求宿主调整画布；`notch` 仅允许游戏模式使用。宿主保持原生画布的尺寸与屏幕锚点固定，收回时为过渡保留 600 ms，再把可交互区域缩到可见浮岛；透明余量允许点击穿透。插件不应逐帧请求原生窗口尺寸。

浮岛交互规则：

- 游戏内鼠标连续可见至少 200 ms、前台窗口未捕获鼠标且未锁定时，移入刘海只恢复为收起的浮岛；点击浮岛后才展开。
- `hoverAllowed: false` 表示游戏正在隐藏或锁定鼠标，或尚未取得可靠的鼠标状态。此时宿主强制收回刘海、拒绝展开并启用鼠标穿透；恢复可见后，需真实移动鼠标才能重新触发。
- 展开后，左键或右键点击外部立即收回。桌面回到收起浮岛，游戏内回到刘海。
- 只移开鼠标、没有点击时，保留 3 秒缓冲；移回来取消计时。
- 外部点击收回后，命中区域变化产生的合成移入事件不会重新打开；再次移动鼠标进入后可恢复。

`onDismiss(callback)` 订阅宿主过滤后的收回事件。Windows 游戏浮窗不获取键盘焦点，因此不能仅靠 `blur` 检测外部点击。宿主使用事件驱动的鼠标按钮监听，始终把事件传递给原应用；插件不会收到全局坐标、按键或其他应用内容。原生辅助进程每 100 ms 检查光标可见性、前台窗口鼠标捕获和极小锁定区域，仅在状态变化时通知宿主；插件只收到 `hoverAllowed`，不会收到全局坐标。最后一个插件窗口关闭时结束监听，父进程退出也会清理原生监听。

浮岛 0.3.3 起，变形只有一个时钟：外壳尺寸、标题栏尺寸、标题内容的淡入淡出和面板显隐都在同一个 requestAnimationFrame 弹簧循环里推进，不再混用定时器、Web Animations 和 CSS transition。标题栏不再有“刘海 / 收起”两套离散布局，宽高每一帧由外壳当前尺寸算出，所以内容始终装在外壳里面，进出刘海时不再整块淡出再淡入。只有标题内容本身要换（封面换成播放器图标、歌名换成播放器名）时才淡出，并且只在完全透明的那一帧替换。保留反向动画的速度，支持系统减少动态效果设置。

若另一台电脑没有动画，先在 Relink → 设置 → 插件 → Relink 浮岛 → 插件设置，查看“跟随系统动画设置”。默认开启，尊重 Windows 的减少动画偏好；关闭后仅浮岛启用完整动画，不修改系统设置。形态、文字淡入淡出和环绕光效使用同一策略，设置即时生效。环绕光效还需单独开启，并在播放音乐时显示；游戏刘海状态暂停环绕。Windows 11 对应设置位于“设置 → 辅助功能 → 视觉效果 → 动画效果”。该选项从浮岛 0.3.2 起提供；更早版本需要更新插件。

Relink 1.0.7 提供可选的动画完成通知：调用 `setDisplayState(state, transitionId)` 开始一次过渡，最后一帧绘制完成后调用 `completeDisplayTransition(transitionId)`。标识必须是正安全整数，每次过渡使用不同的值。宿主忽略已被新过渡取代的完成通知，在动画期间暂时关闭后台限频，完成后恢复；插件没有回应时最多保留 1800 ms。该接口沿用 `window.resize` 授权，不允许指定任意窗口尺寸。旧插件仍走原来的 600 ms 收回逻辑。

浮岛 0.3.4 使用实际渲染的动画时间推进收回，首帧延迟不会消耗整段动画；每帧最多推进 50 ms。支持新接口的宿主收到动画完成通知后才裁剪命中区域。游戏收走鼠标时立即启用点击穿透，视觉过渡继续完成。代码通过检查 `completeDisplayTransition` 是否存在兼容旧客户端；旧客户端仍受固定 600 ms 裁剪约束。Windows Electron 的失焦、外部点击和模拟首帧延迟均已逐帧验证，未代表所有显卡或游戏独占全屏环境。

显示器可选“自动跟随”：游戏运行时跟随游戏窗口所在显示器，平时跟随 Relink 主窗口；也可固定主显示器或指定显示器。已有手动设置会保留，旧安装若保存了“主显示器”，需在插件设置中切换一次。插拔显示器后重新定位，已指定的屏幕重新连接后恢复使用。多屏坐标逻辑有自动测试，仍需在实际多显示器游戏环境验收。

验证覆盖桌面与模拟游戏状态、非焦点窗口、真实系统左右键、点击穿透、连续反向动画、音乐轮询期间标题稳定性。模拟游戏不等同于所有游戏的独占全屏兼容性或游戏帧率测试。

实现参考：[Microsoft LowLevelMouseProc](https://learn.microsoft.com/en-us/windows/win32/winmsg/lowlevelmouseproc)、[Electron screen](https://www.electronjs.org/docs/latest/api/screen)。
